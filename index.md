## Project Title
Explainable Cluster Analysis of Seoul Public Bicycle Rental Patterns

## Project Overview
This project aims to identify and explain different usage patterns in Seoul's public bicycle rental system, Ttareungi. We will use data preprocessing, dimensionality reduction, clustering, and classification to analyze how bicycle rental trips differ based on their duration, distance, and rental time. By identifying groups of similar trips, we hope to better understand how public bicycles are used in Seoul.

## Research Question
Can Seoul's public bicycle rental trips be grouped into distinct usage patterns based on trip duration, distance, and rental time, and what characteristics explain these groups?

## Dataset Description
Our primary dataset is the Seoul Public Bicycle (Ttareungi) Rental History, obtained from the Seoul Open Data Plaza. It contains 18,511,943 rental records collected from January 1 to June 30, 2026, with 16 variables. These include rental and return times, rental stations, trip duration, travel distance, birth year, gender, and user type.
